# Agent notes

Barstronaut is a static Vite + React site published to GitHub Pages at https://barstro.space.

After changing the site, run the build and push `main` to `origin` (`https://github.com/JackMiller825/BARSTRO.git`) so the Pages workflow can update the live domain. Do not invent contract, tax, social, or trading values. Leave unknown fields null in `src/config/project.ts`.

Do not commit `node_modules`, `dist`, the split `.rar` archive, or design preview PNGs.
