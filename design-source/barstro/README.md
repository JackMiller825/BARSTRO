# Barstronaut complete website asset package

Design and content package, not a deployed website. Four approved routes: /, /story, /buy, /community.
Start with specs/page-and-asset-map.md, specs/design-guide.md and content/website-copy.md. Load content/project-config.json; null means pending. No real contract, tokenomics or social addresses are included.
branding/: original approved logo. website/: production art, cutouts, native SVG icons and favicons. social/: exact-size banners and sharing card. previews/v1/: 22 original supplied mockups preserved with their filenames. previews/v2/: current production composition and responsive/state refinements. content/: complete copy and config. specs/: routing, source review, interaction rules and build checks.
Preview images are labeled design mockups and must not be used as webpage backgrounds. Use actual HTML text/buttons and the matching production art. The original v1 generation documentation is included for provenance; its request to pause for feedback is superseded by the user’s authorization to finish this package.
The package is self-contained using system font fallbacks. Fredoka installation is optional and documented. Production art is separate from previews. No external image download is needed.
Use lowercase filenames unchanged. Preserve the approved logo name/ticker. Five bars represent phone reception, never investment performance.
Original mockup inconsistencies (occasional four-bar symbols and small AI-rendered text variations) are retained visibly as v1 history. v2 copy and coded SVG controls supersede them.
No website has been built or published. Launch configuration remains intentionally pending.
